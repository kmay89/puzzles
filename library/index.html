Load a world

This room reads real Minecraft save data. Nothing is uploaded anywhere — the file is opened in your browser and stays there.

Drop region files here the region/ folder of a save, or any r.0.0.mca

Where to get one. Any Minecraft Java world has a region/ folder inside it. The build this room is a tribute to — The Uncensored Library, made by Reporters Without Borders with BlockWorks — is a free download from uncensoredlibrary.com. Download it there, then point this at its region folder.

Big worlds are big: a region file holds up to 1,024 chunks and the whole library is hundreds of them. Load a few at a time.

About this room

A voxel engine written from scratch, and a library to walk around in.

The library

In 2020 Reporters Without Borders and the build studio BlockWorks put a library inside Minecraft. Journalism that had been censored in Russia, Saudi Arabia, Egypt, Mexico and Vietnam was reprinted into books on its shelves, in a game that was not blocked in any of those countries — so the writing could be read where the websites could not. They called it The Uncensored Library.

The building you are standing in is not theirs. It is an original one, built by code in this repository, in tribute — so there is somewhere to walk before you have downloaded anything. The real one is at uncensoredlibrary.com, free, and this room will render it if you point it at the download.

What is actually running

  • Nothing of Mojang's. No game code and no game textures. A Minecraft world stores block names, not pictures, so this room looks them up in its own palette and paints every texture procedurally when the page loads.
  • An NBT reader and an Anvil reader, written here from the documented formats — the same kind of thing as a PNG decoder.
  • A greedy mesher, so a wall is a few rectangles instead of a few thousand cubes.
  • Raw WebGL. No engine, no library, no build step.
